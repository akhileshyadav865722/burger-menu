## 📌 Project Overview

**Burger Menu** is a responsive, modern web navigation component built with **HTML5** and **CSS3**. 

It delivers a clean, mobile-friendly hamburger menu drawer designed for seamless user experience across mobile phones, tablets, and desktop interfaces.

## ✨ Features

- 📱 **Mobile-First Responsive Design**: Adapts cleanly across different device viewports.
- ✨ **Smooth CSS Transitions**: Animated slide-in / fade-in drawer transitions and interactive hover states.
- 🎨 **Modern Typography & Styling**: Custom styling with clean shadows, spacing, and icon integration.
- 🚀 **Zero Dependencies**: Pure HTML and CSS without heavy external frameworks.

---

## 🛠️ Technologies Used

- **HTML5**: Semantic markup and navigational structure.
- **CSS3**: Flexbox layout, media queries, CSS transitions, and styling.

   ```bash

   cd burgermenu
   ```

   - Double-click `menu/main.html` to open it in your browser.
   - Or open using the VS Code **Live Server** extension.
